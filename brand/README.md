## Concept

**phzyx ≈ physics**

- **Integration ∫** — continuous evolution of schema/state  
- **Quantum orbits** — desired vs observed state; multi-language ports  
- **Binary** — software, drivers, exact systems  

## Styling stance

- **No** default Bootstrap / Material / stock admin template look  
- **Yes** Geist + Inter (free OFL), hairline chrome, glass windows, compact 13px controls  
- **Primary themes (enterprise):** **Magical White** + **Stellar Dark** (equal quality)  
- **Secondary:** System Ambient (OS follow → White/Dark)  

Full rules: [DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md).
